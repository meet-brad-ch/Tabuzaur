Help

Tabuzaur keeps the pages you work with in collections. You build a collection from the tabs that are open, by dragging. A saved link jumps to its tab when the tab is open. All data stays on this computer.

Version ?

Install

  1. Download Tabuzaur-vX.Y.Z.zip from the Releases page of the project and unzip it into a folder that stays. Chrome loads the extension from that folder every time it starts.

  2. Open chrome://extensions and enable Developer mode, top right.

  3. Click Load unpacked and choose the unzipped folder.

  4. The Tabuzaur card appears with its ID and version. This help page opens by itself once. To update later, unzip the new release over the same folder and click the reload icon on the card.

Open Tabuzaur

There are three ways to open the page. Each one brings the page to the front when it is already open.

  • The toolbar button. Click the dinosaur next to the address bar. Pin it there with the puzzle-piece menu if Chrome hides it.
  • Alt+T. Chrome assigns this key at install when no other extension uses it. The page header shows the key in effect. If it shows No shortcut assigned, click it and set a key on chrome://extensions/shortcuts.
  • Start page. Copy the ID from the Tabuzaur card. In Chrome Settings, open On startup, choose Open a specific page or set of pages, click Add a new page and enter chrome-extension://<id>/tabs.html.

The page

  • Header. Search, a field to create a collection, Export, Import, the theme button and this help.
  • Open tabs. The thin rail on the left shows how many tabs are open. Rest the pointer on it and the panel opens with every open tab, grouped by window.
  • Pin. The pin at the top of the panel keeps it open as a column. Click it again and the panel closes when the pointer leaves it.

Collections

  • Create. Type a name in the header field and click Create. The new collection gets its own color.
  • Add a link. Drag a tab from the panel onto a collection. The link keeps the title, the address and the icon of the tab. Tabuzaur refuses a link that is already in that collection, with a notice.
  • Open a link. Click anywhere on the link row. When the page is open in a tab, Tabuzaur jumps to that tab. Otherwise it opens the page in a new tab.
  • Reorder. Drag a link up or down inside its collection. A green line shows where it lands. Drag it onto another collection to move it there.
  • Edit a link. Rest the pointer on the link and click the pen. Change the title or the address. Enter saves, Escape cancels.
  • Remove a link. Rest the pointer on the link and click the cross.
  • Rename a collection. Click the pen in the colored band.
  • Move a collection. Drag the colored band onto another collection. A green line between the cards shows where it lands.
  • Delete a collection. Click the trash icon in the band. Tabuzaur asks first.

Find

Type in the search field in the header. Only collections with a match stay on the page, and Tabuzaur marks the match in the names and the links. The panel has its own filter for open tabs.

Backup

Export downloads all collections as one JSON file named tabuzaur-backup-YYYY-MM-DD.json. Import reads such a file and asks what to do with it.

  • Replace removes the collections you have and loads the file.
  • Merge adds the file to what you have. Collections with the same name join. Links you already have stay as they are. Nothing is removed.

The same file carries collections to another computer.

Theme

The round button at the right of the header cycles through three settings: follow the system, light, dark.

Keyboard

Alt+TOpen Tabuzaur from any tab, or bring it to the front.
EnterSave a name or a link you are editing.
EscapeLeave the editor without a change. Close the import question.
TabMove through the fields and buttons. The pen, cross and trash buttons show when they have the focus.

Privacy

Tabuzaur asks for two permissions: tabs, to list and open tabs, and storage, to keep the collections. It stores everything in Chrome's local storage on this computer. It makes no network request, has no account and sends nothing anywhere. Your backup file is the only copy outside Chrome, and you make it.
